# Mission: Indigestible

A gamified review app for Food & Exercise Science standard 3.5 (Dietary Fiber) at Little Chute High School.

Students clock in as recruits on the fiber Clean-Up Crew and work eight jobs leveled to the standard:

- Level 1: Orientation Day, Polysaccharide Lineup, Super-Glue Squad
- Level 2: The Dynamic Duo, Go Fiber!
- Level 3: Body Works, Dispatch Desk
- Final review: Smarty Plants

The Mission Debrief page downloads as a PNG or PDF for portfolios or unit preparation evidence.

## Files

- `index.html` is the whole app (HTML, CSS and JavaScript in one file).
- `img/` holds the artwork.

No build step. Open `index.html` in a browser, or host the folder on any static host such as Vercel.
